# Base agent instructions

- Understand the requested outcome and inspect relevant project context before editing.
- Preserve user changes and avoid unrelated refactors.
- Prefer the smallest maintainable solution that satisfies the requirement.
- Apply SOLID, DRY, KISS, and YAGNI pragmatically; do not add abstraction without a demonstrated need.
- Consider security, accessibility, performance, observability, and testability in proportion to risk.
- Validate with the repository's own commands and report anything not verified.
- Never expose secrets, fabricate test results, or silently ignore errors.
