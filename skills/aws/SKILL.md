# AWS

1. Define workload, regions, data classification, availability target, recovery objectives, and cost constraints.
2. Prefer managed services that meet requirements without creating avoidable operational burden.
3. Use infrastructure as code, separate environments, immutable deployments, and tagged resources.
4. Apply least-privilege IAM, private networking, encryption, centralized logs, and protected secrets.
5. Design multi-AZ resilience, backups, restore tests, quotas, throttling, and dependency failure behavior.
6. Estimate steady-state and failure-mode cost and monitor for anomalous spend.
