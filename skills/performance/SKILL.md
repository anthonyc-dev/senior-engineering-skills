# Performance

1. Define the user-facing metric, workload, percentile, budget, and representative environment.
2. Capture a baseline before changing code and profile the dominant cost.
3. Optimize algorithms, I/O, query plans, payloads, rendering, or caching according to evidence.
4. Bound memory, concurrency, queues, retries, and fan-out.
5. Preserve correctness and avoid shifting cost to another constrained resource.
6. Re-measure under the same conditions and document trade-offs and regression thresholds.
