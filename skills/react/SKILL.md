# React

1. Inspect the React version, rendering model, component library, and local conventions.
2. Keep components focused, declarative, accessible, and preferably under 150 lines.
3. Keep functions focused and preferably under 40 lines; extract behavior into feature hooks or services.
4. Derive state instead of synchronizing duplicates and place state at the narrowest shared owner.
5. Use effects only for external synchronization; declare dependencies and cleanup correctly.
6. Preserve stable keys, semantic HTML, keyboard access, focus behavior, and visible error states.
7. Optimize only measured render or bundle problems; verify with focused component and interaction tests.
