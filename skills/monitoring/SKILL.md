# Monitoring

1. Define user journeys, service-level indicators, objectives, and error-budget policy.
2. Instrument request rate, errors, latency, saturation, queueing, and critical business outcomes.
3. Propagate trace and correlation context across process and network boundaries.
4. Alert on actionable symptoms with clear ownership, severity, runbook, and deduplication.
5. Separate liveness from readiness and avoid health checks that amplify dependency failures.
6. Validate dashboards and alerts through controlled failure or replay where safe.
