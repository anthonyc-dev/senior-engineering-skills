# Git

1. Inspect repository status, branch, upstream, and relevant diff before mutating history or files.
2. Preserve unrelated and uncommitted user work.
3. Stage only intended changes and keep commits cohesive with clear imperative messages.
4. Prefer non-destructive recovery and create a backup reference before risky history edits.
5. Never force-push, discard changes, or rewrite shared history without explicit authorization.
6. Verify the final diff and status after each operation.
