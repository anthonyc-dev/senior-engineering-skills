# Flutter

1. Confirm Flutter and Dart versions, target platforms, state approach, routing, and project conventions.
2. Organize by feature, keep widgets declarative, and move business behavior out of the UI.
3. Model state immutably and make loading, empty, success, and failure states explicit.
4. Use `const` widgets, stable keys, lazy lists, and bounded rebuild scopes.
5. Preserve semantic labels, keyboard behavior, text scaling, contrast, and platform conventions.
6. Keep secrets off-device and validate authorization server-side.
7. Run format, analyze, unit/widget tests, and platform builds appropriate to the change.
