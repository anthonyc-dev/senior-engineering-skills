# DevOps

1. Map source, build, test, artifact, promotion, deployment, verification, and rollback stages.
2. Build once and promote immutable, signed, traceable artifacts between environments.
3. Keep infrastructure and pipeline definitions versioned, reviewed, repeatable, and least-privileged.
4. Isolate secrets from code and logs and prefer short-lived workload identity.
5. Use progressive delivery when risk warrants it and automate health-based rollback safely.
6. Track lead time, deployment frequency, change failure rate, and recovery time.
