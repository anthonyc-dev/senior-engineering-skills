# JavaScript

1. Confirm runtime, module system, supported language level, and lint rules.
2. Prefer ESM, immutable bindings, pure transformations, and small explicit functions.
3. Handle promises deliberately; avoid floating promises, swallowed errors, and accidental sequential I/O.
4. Validate external data at runtime and document public contracts with JSDoc when types are unavailable.
5. Avoid implicit coercion, prototype mutation, shared mutable state, and dynamic code execution.
6. Test edge cases and run the repository's lint and test commands.
