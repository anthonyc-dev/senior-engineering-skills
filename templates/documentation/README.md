# Decision documentation

Copy [decision-record.md](decision-record.md) into the project's existing architecture-decision directory and give it a descriptive name. Replace each instruction paragraph with project facts. Keep short decisions short; omit irrelevant detail with a reason.

Validate the record against the actual implementation, test evidence, rollout owner, and recovery procedure. Never include credentials, private customer data, or unverified success claims. This document is a writing template, not an accepted project decision.
